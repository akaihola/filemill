# ADR 0031: `set()` / `setVar()` write guards

Date: 2026-08-16

## Context

The static edition needs a documented decision for this design choice.

## Decision

`set()` / `setVar()` write guards

## Measurement

Re-writing the width or a custom property a column already has still relays out all of its rows

## Consequences

The static edition follows this decision. The measurement above records the basis for maintaining and evaluating it.
