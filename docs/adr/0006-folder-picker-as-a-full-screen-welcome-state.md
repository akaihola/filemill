# ADR 0006: Folder picker as a full-screen welcome state

Date: 2026-08-16

## Context

The static edition needs a documented decision for this design choice.

## Decision

Folder picker as a full-screen welcome state

## Measurement

`showDirectoryPicker()` needs a user gesture and there is nothing to show before one exists

## Consequences

The static edition follows this decision. The measurement above records the basis for maintaining and evaluating it.
